## How it works

The tools run entirely in your browser. The logic is checked, case by case, against the project's Python version, which is tested with real Pokémon: what you see here is what the game would do.

The game rules come from FireRed's reconstructed source code (pret/pokefirered), built as the Switch version. Species, move and item data are read from the compiled ROM itself, not typed in by hand.
