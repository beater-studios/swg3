:::tip Prefere fazer junto?
O [guia com o Professor Oak](/codes?tour=codes-typing) mostra na própria página Códigos como conferir um código e digitar no jogo.
:::

O [gerador de E-Sh4rk](https://e-sh4rk.github.io/CodeGenerator/index_frlg.html) tem uma coleção grande de códigos. No Switch, escolha sempre a versão `eng10` (English Switch): as outras são do cartucho e podem travar ou estragar o save.

| para | códigos |
|---|---|
| Criar Pokémon | Start wild battle with any Pokemon, Create any Gift Pokemon, Generate egg with any PID, Create 6IV Egg, Create Egg with Custom Hidden Power |
| Ver dados de um Pokémon | Read Pokemon PID, Read Pokemon TID and SID, Read Pokemon IVEA field, Read EVs field |
| Mudar um Pokémon | Change experience, Change IVs and ability, Change EVs, Change Pokerus and Origin Data, Make any Pokémon Shiny, Teach Pokemon Any Move |
| Treinador e itens | Change TID and SID, Get any item, todas as Poké Balls, TMs e berries |
| Mundo | Get National Dex via NPC, Create Tradeback NPC (evolução por troca sozinho), teletransporte, respawn de lendários |

:::note O que ainda não tem versão para o Switch
Mudar nome do treinador, nome do OT de um Pokémon e PID. Nature também não tem código: ela vem do PID. Para um Pokémon com tudo do seu jeito, use o [Base64 writer](/guides/base64).
:::
