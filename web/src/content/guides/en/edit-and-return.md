1. **Set up the trade.** Create any Pokémon here and generate the trade recipe with "Save what you send" filled in.
2. **Send yours.** In the game, trade away the Pokémon you want to edit. The PC saves the file.
3. **Edit it.** Open the file in [Editor](/editor), click Edit and check it.
4. **Get it back.** Generate the recipe with the edited Pokémon and trade again.

:::note Not possible yet
It depends on the PC trade program, which is still being built.
:::
