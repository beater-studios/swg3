The [E-Sh4rk code generator](https://e-sh4rk.github.io/CodeGenerator/index_frlg.html) has a big collection of codes. On Switch, always pick version `eng10` (English Switch): the others are for the cartridge and can crash the game or corrupt your save.

| for | codes |
|---|---|
| Create Pokémon | Start wild battle with any Pokemon, Create any Gift Pokemon, Generate egg with any PID, Create 6IV Egg, Create Egg with Custom Hidden Power |
| View a Pokémon's data | Read Pokemon PID, Read Pokemon TID and SID, Read Pokemon IVEA field, Read EVs field |
| Change a Pokémon | Change experience, Change IVs and ability, Change EVs, Change Pokerus and Origin Data, Make any Pokémon Shiny, Teach Pokemon Any Move |
| Trainer and items | Change TID and SID, Get any item, all Poké Balls, TMs and berries |
| World | Get National Dex via NPC, Create Tradeback NPC (trade evolutions on your own), teleport, legendary respawn |

:::note What doesn't have a Switch version yet
Changing the trainer name, a Pokémon's OT name and PID. Nature has no code either: it comes from the PID. For a Pokémon that's exactly how you want it, use the [Base64 writer](/guides/base64).
:::
