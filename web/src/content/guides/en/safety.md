ACE codes write straight into the game's memory. It almost always works, but one wrong character can crash the game or break a Pokémon. These precautions save you a lot of trouble.

1. **Save before anything else.** Before the Mail glitch, before every code and before every trade. If something goes wrong, just turn the game off without saving and go back.
2. **Keep Box 13 clear.** Box 13 from slot 7 on, and every box after it, must be empty when you trigger a code. Never keep anything important in Box 13, slots 7 to 9.
3. **Move the glitch species one at a time.** In the PC, under MOVE POKÉMON, the Select button switches the hand to the mode that moves several Pokémon together. Don't pick up 0x0351 in that mode: according to the community, it disappears and you have to redo the Mail glitch. If the hand changed, press Select again and pick it up with A as usual.

:::warn Pokémon HOME
Don't take Pokémon created or changed with ACE or with this site to HOME. It's an online service run by Nintendo and The Pokémon Company, and nobody knows what happens to your whole save if one of them gets detected.
:::

:::tip When HOME comes to FireRed and LeafGreen
Pokémon HOME support for FireRed and LeafGreen on Switch is expected in October 2026, probably together with a game update. After that update, codes and addresses may change: before using any code, check that it has been tested on the new version.
:::
