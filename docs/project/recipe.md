# Recipe (ESP32)

JSON file generated by the site that tells the PC program what to do with the ESP32 board and tells the player what to do at each step. Code in `src/swg3/recipe.py`; checked from the command line with `swg3 recipe check FILE`.

## Format v1

```json
{
  "format": "swg3-recipe",
  "version": 1,
  "created": "2026-09-29T12:00:00Z",
  "game": {"title": "firered", "language": "eng", "revision": 10},
  "action": "trade",
  "offer": {
    "format": "pk3",
    "data": "<80 bytes in hexadecimal, game format (encrypted)>",
    "species": 6,
    "species_name": "CHARIZARD",
    "nickname": "CHARIZARD",
    "evolves_to": null
  },
  "receive": {"save_as": "received.pk3"},
  "steps": [{"who": "player", "text": "Save the game before you start."}],
  "notes": ["..."]
}
```

| field | rule |
|---|---|
| `game.title` | `firered` or `leafgreen`; `language` only `eng`; `revision` only 10 |
| `action` | only `trade` in v1 |
| `offer.data` | box pk3 (80 bytes) in the game format; the species must match `offer.species` |
| `offer.evolves_to` | species the Pokémon evolves into on arrival (`GetEvolutionTargetSpecies`, trade mode; an Everstone prevents it) |
| `receive` | `{"save_as": "arquivo.pk3"}` to save what the player gives, or `null` |
| `steps` | `who` is `pc` or `player`; text to display in order |

## Guarantees

- `recipe.trade` and `recipe.load` reject Pokémon with a validation error (`validate.check`): an invalid Pokémon can corrupt the save.
- The PC recalculates the party level and stats when setting up the trade: the recipe carries only the box format.
- New format version: increment `version` and keep reading the previous one while files in use exist.

## Player flow

Follows the pokeldn trade path (Union Room, the middle receptionist on the 2nd floor of the Pokémon Center). Not verified in this project: it depends on the trade host, still under construction.

## Uses

- Take a Pokémon built on the site to the game.
- Edit and return: receive the player's Pokémon (offering any other), edit it on the site and generate the recipe back.
